# Pocket Agent

A tiny iPhone-friendly AI web app.

## Deploy on Vercel
1. Put these files in a GitHub repo, or upload the folder to Vercel.
2. Add an environment variable named `OPENAI_API_KEY` in Vercel Project Settings > Environment Variables.
3. Deploy.
4. Open the deployed URL in Safari on iPhone.
5. Tap Share > Add to Home Screen.

The API key stays server-side in the Vercel function.
